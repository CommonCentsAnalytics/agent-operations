# Optional Skills

Optional skills are catalog entries that teams install when they need a specific capability beyond the bundled baseline. They use the same catalog install, audit, update, and reset mechanics as bundled skills.

For the catalog mechanics, start with the [Skills reference](https://docs.paperclip.ing/reference/skills/#3-app-shipped-catalog). For the baseline catalog, see the [Bundled skills](https://docs.paperclip.ing/reference/skills/bundled/) index.

## Browser

- [Agent Browser](https://docs.paperclip.ing/reference/skills/optional/browser/agent-browser/) — drive a supervised browser for verification, screenshots, and JavaScript-rendered pages.

## Content

- [Release Announcement](https://docs.paperclip.ing/reference/skills/optional/content/release-announcement/) — turn release changes into concise public-facing announcement copy.
- [Simplified English](https://docs.paperclip.ing/reference/skills/optional/content/simplified-english/) — write user-facing comments, plans, and documents in ASD-STE100 Simplified Technical English so readers understand them the first time.

## Finance

- [Ramp](https://docs.paperclip.ing/reference/skills/optional/finance/ramp/) — follow Ramp's official agent playbooks (onboarding, cards, spend controls) under Paperclip's approval gates and host allowlist.

## Product

- [Design Critique](https://docs.paperclip.ing/reference/skills/optional/product/design-critique/) — review a product or UI flow for clarity, hierarchy, and execution risks.

## Research

- [Last30Days](https://docs.paperclip.ing/reference/skills/optional/research/last30days/) — research recent public discussion about a topic across Reddit, X, YouTube, and the web.

## Software Development

- [Prepare MCP Integration](https://docs.paperclip.ing/reference/skills/optional/software-development/prepare-mcp-integration/) — research a new MCP or vendor integration, gate it on exact-revision human approval, then ship one governed Paperclip connector per approved connection.
