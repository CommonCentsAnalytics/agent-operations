# Bundled Skills

Bundled skills are catalog entries that ship with Paperclip's baseline kit. They are versioned with the app, browseable through the catalog API, and installable into a company when a team needs that operating pattern.

For the catalog mechanics, start with the [Skills reference](https://docs.paperclip.ing/reference/skills/#3-app-shipped-catalog). For optional add-ons, see the [Optional skills](https://docs.paperclip.ing/reference/skills/optional/) index.

## Docs

- [Doc Maintenance](https://docs.paperclip.ing/reference/skills/bundled/docs/doc-maintenance/) — keep project documentation aligned with recent code and feature changes.

## Paperclip operations

- [Issue Triage](https://docs.paperclip.ing/reference/skills/bundled/paperclip-operations/issue-triage/) — classify stale, blocked, in-review, or stalled Paperclip issues and choose the next action.
- [Status Card Query](https://docs.paperclip.ing/reference/skills/bundled/paperclip-operations/status-card-query/) — author Paperclip status cards, and compile a card's prose prompt into bounded search queries and its first summary.
- [Task Planning](https://docs.paperclip.ing/reference/skills/bundled/paperclip-operations/task-planning/) — turn approved plans into Paperclip issues with ownership, dependencies, and acceptance criteria.

## Product

- [Wireframe](https://docs.paperclip.ing/reference/skills/bundled/product/wireframe/) — produce low-fidelity UI wireframes as standalone SVG deliverables.

## Quality

- [QA Acceptance](https://docs.paperclip.ing/reference/skills/bundled/quality/qa-acceptance/) — define observable acceptance criteria and focused verification passes.

## Software development

- [GitHub PR Workflow](https://docs.paperclip.ing/reference/skills/bundled/software-development/github-pr-workflow/) — prepare, inspect, update, and communicate GitHub pull request work.
